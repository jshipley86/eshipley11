# eshipley11.com – Official Recruiting Profile for Emma Shipley

This repository contains the source code for **eshipley11.com**, the official flag football recruiting profile for **Emma Shipley (Class of 2028)**.  
The site is built using lightweight HTML/CSS and hosted through **GitHub Pages** for fast loading, easy updates, and strong SEO performance.
